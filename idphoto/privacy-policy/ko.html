ID Photo 개인정보처리방침

최종 업데이트: 2026년 9월 14일

ID Photo는 사용자의 개인정보를 존중합니다.

사진 처리

선택하거나 촬영한 사진은 사용자 기기에서 로컬로 처리됩니다. 개발자는 사진을 업로드, 수집, 저장 또는 공유하지 않습니다.

기기 내 저장 및 공유

앱은 사진을 처리하는 동안 기기 내 캐시에 임시 사진 파일을 만듭니다. 이 파일은 사용자의 기기에 남으며 개발자는 접근할 수 없습니다. 사용자는 Android의 앱 저장공간 설정에서 캐시 파일을 삭제할 수 있습니다.

처리 결과는 사용자가 선택한 경우에만 기기의 공유 저장공간으로 내보내거나 다른 앱과 공유합니다. 사용자는 갤러리나 파일 관리자로 내보낸 파일을 관리하고 삭제할 수 있습니다. 공유 대상과 공유 후 사진의 처리는 사용자가 선택한 앱 또는 서비스에서 관리합니다.

계정 정보

ID Photo는 계정 생성이나 로그인을 요구하지 않습니다.

선택적 구매

개발자를 지원하기 위한 선택적 일회성 구매를 제공합니다. 결제는 Google Play에서 처리하며 개발자는 전체 결제 카드 정보를 받거나 저장하지 않습니다. 구매로 기능이 잠금 해제되거나 제한되지 않습니다.

버그 신고

사용자는 이메일 앱을 통해 자발적으로 의견이나 버그 신고를 보낼 수 있습니다. 앱은 신고 유형, 선택한 국가 및 증명서 유형, 앱 이름 및 애플리케이션 ID, 앱 버전, 기기 제조사 및 모델, Android 버전, 사용자가 입력한 신고 내용을 포함하는 이메일을 준비합니다. 정보는 사용자가 이메일을 검토하고 보낸 후에만 전송됩니다.

개발자는 발신자의 이메일 주소와 이메일 내용을 받습니다. 이 이메일과 정보는 앱 개선, 버그 수정 및 관련 문제 추적에만 사용되며, 해당 목적에 필요한 기간 동안 보관됩니다. 사용자는 chickeneren43@gmail.com에 연락하여 제출한 이메일과 관련 정보의 삭제를 요청할 수 있습니다. 관련 이메일 서비스 제공업체도 각자의 개인정보처리방침에 따라 이메일을 처리합니다.

데이터 수집

개발자는 버그 신고 항목에 설명된 대로 사용자가 이메일로 자발적으로 제출한 정보를 받습니다. Google ML Kit는 아래에 설명된 SDK 측정 데이터를 별도로 처리합니다.

Google ML Kit

ID Photo는 Google ML Kit를 사용하여 기기에서 사진을 처리합니다. ML Kit는 입력 사진을 기기 내에서 처리하며 사진이나 처리 결과를 Google 서버로 보내지 않습니다.

ML Kit는 SDK 성능, 사용 및 진단 데이터를 Google에 전송합니다. Google에 따르면 여기에는 기기 및 앱 정보, 설치별 식별자, 성능 지표, API 구성, 입력 및 출력 크기, 기능 버전, 이벤트 유형, 오류 코드가 포함됩니다. Google은 이 데이터를 API 성능 측정, 디버깅, 유지보수 및 개선, 부적절한 사용이나 악용 탐지에 사용합니다. 모델이 앱에 포함된 기능에도 적용됩니다. 측정 데이터는 HTTPS를 통해 암호화되어 전송됩니다.

자세한 내용은 Google ML Kit Terms & Privacy, ML Kit Android data disclosure, Google Privacy Policy를 참조하세요.
