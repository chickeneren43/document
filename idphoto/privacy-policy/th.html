ID Photo เคารพความเป็นส่วนตัวของคุณ

การประมวลผลรูปภาพ

รูปภาพที่เลือกหรือถ่ายจะประมวลผลภายในอุปกรณ์ นักพัฒนาไม่อัปโหลด รวบรวม จัดเก็บ หรือแบ่งปันรูปภาพ

การจัดเก็บในอุปกรณ์และการแชร์

แอปจะสร้างไฟล์รูปภาพชั่วคราวในแคชภายในอุปกรณ์ระหว่างการประมวลผลรูปภาพ ไฟล์เหล่านี้จะอยู่ในอุปกรณ์ของผู้ใช้และผู้พัฒนาไม่สามารถเข้าถึงได้ ผู้ใช้สามารถลบไฟล์แคชผ่านการตั้งค่าพื้นที่เก็บข้อมูลของแอปใน Android

ผลลัพธ์ที่ประมวลผลแล้วจะถูกส่งออกไปยังพื้นที่เก็บข้อมูลที่ใช้ร่วมกันของอุปกรณ์หรือแชร์ไปยังแอปอื่นเฉพาะเมื่อผู้ใช้เลือกดำเนินการเท่านั้น ผู้ใช้สามารถจัดการและลบไฟล์ที่ส่งออกผ่านแกลเลอรีหรือตัวจัดการไฟล์ ปลายทางและการจัดการรูปภาพหลังจากแชร์ขึ้นอยู่กับแอปหรือบริการที่ผู้ใช้เลือก

ข้อมูลบัญชี

ID Photo ไม่กำหนดให้ผู้ใช้สร้างบัญชีหรือเข้าสู่ระบบ

การซื้อที่ไม่บังคับ

แอปมีการซื้อครั้งเดียวแบบไม่บังคับเพื่อสนับสนุนนักพัฒนา Google Play เป็นผู้ประมวลผลการชำระเงิน นักพัฒนาไม่ได้รับหรือจัดเก็บข้อมูลบัตรทั้งหมด การซื้อไม่ปลดล็อกหรือจำกัดฟังก์ชันใด

การรายงานข้อบกพร่อง

ผู้ใช้สามารถส่งความคิดเห็นหรือรายงานข้อบกพร่องผ่านแอปอีเมลโดยสมัครใจ แอปจะเตรียมอีเมลที่มีประเภทรายงาน ประเทศและประเภทเอกสารที่เลือก ชื่อและรหัสแอปพลิเคชัน เวอร์ชันแอป ผู้ผลิตและรุ่นอุปกรณ์ เวอร์ชัน Android และข้อความรายงานที่ผู้ใช้กรอก ข้อมูลจะถูกส่งต่อเมื่อผู้ใช้ตรวจสอบและส่งอีเมลแล้วเท่านั้น

ผู้พัฒนาจะได้รับที่อยู่อีเมลของผู้ส่งและเนื้อหาอีเมล อีเมลและข้อมูลเหล่านี้ใช้เพื่อปรับปรุงแอป แก้ไขข้อบกพร่อง และติดตามปัญหาที่เกี่ยวข้องเท่านั้น และจะเก็บไว้ตามระยะเวลาที่จำเป็นสำหรับวัตถุประสงค์ดังกล่าว ผู้ใช้สามารถขอให้ลบอีเมลที่ส่งและข้อมูลที่เกี่ยวข้องโดยติดต่อ chickeneren43@gmail.com ผู้ให้บริการอีเมลที่เกี่ยวข้องจะประมวลผลอีเมลตามนโยบายความเป็นส่วนตัวของตนด้วย

การเก็บรวบรวมข้อมูล

ผู้พัฒนาได้รับข้อมูลที่ผู้ใช้ส่งทางอีเมลโดยสมัครใจตามที่อธิบายในส่วนการรายงานข้อบกพร่อง ส่วน Google ML Kit จะประมวลผลข้อมูลตัวชี้วัดของ SDK แยกต่างหากตามที่อธิบายด้านล่าง

Google ML Kit

ID Photo ใช้ Google ML Kit เพื่อประมวลผลรูปภาพบนอุปกรณ์ ML Kit ประมวลผลรูปภาพที่ป้อนเข้ามาภายในอุปกรณ์ และไม่ส่งรูปภาพหรือผลลัพธ์การประมวลผลไปยังเซิร์ฟเวอร์ของ Google

ML Kit ส่งข้อมูลประสิทธิภาพ การใช้งาน และการวินิจฉัยของ SDK ไปยัง Google ตามข้อมูลของ Google ข้อมูลนี้รวมถึงข้อมูลอุปกรณ์และแอปพลิเคชัน ตัวระบุสำหรับแต่ละการติดตั้ง ตัวชี้วัดประสิทธิภาพ การกำหนดค่า API ขนาดข้อมูลเข้าและออก เวอร์ชันฟีเจอร์ ประเภทเหตุการณ์ และรหัสข้อผิดพลาด Google ใช้ตัวชี้วัดเหล่านี้เพื่อวัดประสิทธิภาพ แก้ไขข้อผิดพลาด ดูแลและปรับปรุง API รวมถึงตรวจจับการใช้งานที่ไม่เหมาะสมหรือการใช้งานในทางที่ผิด ทั้งนี้ยังใช้กับฟีเจอร์ที่รวมโมเดลไว้ในแอปด้วย ข้อมูลตัวชี้วัดจะถูกเข้ารหัสระหว่างการส่งผ่าน HTTPS

ดูรายละเอียดได้ที่ Google ML Kit Terms & Privacy, ML Kit Android data disclosure และ Google Privacy Policy
